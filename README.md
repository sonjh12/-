# Birthday Gift Website

생일을 중심으로 축하 메시지와 선물 금액을 주고받는 웹사이트입니다.

## 주요 기능
- 회원가입/로그인
- 생일 등록 및 수정
- **상대방 생일 당일에만** 메시지 + 선물 금액 작성 가능
- 받은 사람은 **올해 생일이 지난 후에만** 메시지 열람 가능
- 받은 메시지에 답장 남기기
- 받은 총 선물 금액 합계 확인

## 실행 방법
정적 사이트이므로 간단한 로컬 서버로 실행할 수 있습니다.

```bash
python3 -m http.server 4173
```

브라우저에서 `http://localhost:4173` 접속.

## 데이터 저장
- 브라우저 `localStorage`를 사용합니다.
- 키:
  - `bgw_users`
  - `bgw_gifts`
  - `bgw_session`
